Cores

Paleta do TCMRio: marinho de marca e celeste de acento sobre fundo branco. O texto é grafite neutro; o marinho fica só no que é clicável e no item ativo. Cor forte só aparece para ambiente e para estado; o celeste é decoração e nunca fica sob texto.

Ambientes

Cada ambiente tem uma cor fixa em todas as telas. A etiqueta de ambiente é uma sigla em caixa reta com borda; a pílula de estado é arredondada e preenchida. Assim PRD (vermelho) não se confunde com erro, nem pela cor nem pela forma.

Pílulas de estado Enviado Na fila Divergente Erro Neutro
Seletor de servidor: lista fechada, agrupada por ambiente (troque para ver a etiqueta mudar)
Faixa de contexto: fixa no topo de toda tela que consulta um servidor

Tipografia

Segoe UI para tudo; Cascadia Mono para o que se copia (caminhos, versões, ids, servidores). Texto auxiliar nunca abaixo de 12px; números em colunas usam algarismos tabulares.
